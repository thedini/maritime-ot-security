# Team Project Grading Rubric

## Overview

This rubric is used to assess team-based projects and activities in the Maritime OT Security course. Projects are graded out of 100 points across three categories: Content (50%), Technical Depth (30%), and Presentation (20%).

## Grading Categories

### 1. Content (50 points)

Assessment of the substance, accuracy, and completeness of the project deliverables.

#### Research and Background (15 points)

| Score | Criteria |
|-------|----------|
| **13-15** (Excellent) | Comprehensive research with multiple authoritative sources; thorough background information; clearly establishes context and relevance to maritime OT security |
| **11-12** (Proficient) | Good research with adequate sources; solid background information; establishes context |
| **9-10** (Developing) | Basic research with some gaps; limited background information; weak context |
| **0-8** (Needs Improvement) | Minimal research; insufficient background; no clear context |

#### Technical Accuracy (20 points)

| Score | Criteria |
|-------|----------|
| **18-20** (Excellent) | All technical information is accurate and up-to-date; demonstrates deep understanding; correctly applies course concepts; no factual errors |
| **16-17** (Proficient) | Most technical information accurate; good understanding; minor errors that don't impact conclusions |
| **14-15** (Developing) | Some technical inaccuracies; basic understanding; several errors |
| **0-13** (Needs Improvement) | Multiple significant errors; misunderstanding of key concepts; outdated information |

#### Completeness (15 points)

| Score | Criteria |
|-------|----------|
| **14-15** (Excellent) | All project requirements met and exceeded; comprehensive coverage of topic; includes additional valuable insights |
| **12-13** (Proficient) | All requirements met; good coverage; meets expectations |
| **10-11** (Developing) | Most requirements met; some gaps in coverage |
| **0-9** (Needs Improvement) | Missing significant requirements; incomplete coverage |

**Content Subtotal**: \_\_\_\_\_ / 50 points

---

### 2. Technical Depth (30 points)

Assessment of technical sophistication, methodology, and analytical rigor.

#### Methodology and Approach (12 points)

| Score | Criteria |
|-------|----------|
| **11-12** (Excellent) | Sophisticated, well-designed methodology; clearly explained procedures; replicable approach; justifies design choices |
| **10** (Proficient) | Sound methodology; clear procedures; mostly replicable |
| **8-9** (Developing) | Basic methodology with some gaps; procedures unclear in places |
| **0-7** (Needs Improvement) | Weak or unclear methodology; not replicable |

#### Technical Implementation (10 points)

| Score | Criteria |
|-------|----------|
| **9-10** (Excellent) | Sophisticated technical implementation; efficient code/tools; demonstrates advanced techniques; well-integrated components |
| **8** (Proficient) | Good technical implementation; functional code/tools; uses appropriate techniques |
| **6-7** (Developing) | Basic implementation; code/tools work but inefficient; limited techniques |
| **0-5** (Needs Improvement) | Poor implementation; non-functional or very limited |

#### Analysis and Insights (8 points)

| Score | Criteria |
|-------|----------|
| **7-8** (Excellent) | Deep, insightful analysis; identifies patterns and implications; makes connections to broader maritime security context; original thinking |
| **6** (Proficient) | Good analysis; identifies key findings; makes relevant connections |
| **4-5** (Developing) | Basic analysis; surface-level findings; limited connections |
| **0-3** (Needs Improvement) | Minimal analysis; no insights or connections |

**Technical Depth Subtotal**: \_\_\_\_\_ / 30 points

---

### 3. Presentation (20 points)

Assessment of communication effectiveness, organization, and delivery.

#### Organization and Structure (6 points)

| Score | Criteria |
|-------|----------|
| **6** (Excellent) | Exceptionally well-organized; logical flow; clear sections; easy to navigate; professional structure |
| **5** (Proficient) | Well-organized; good flow; clear sections |
| **4** (Developing) | Adequate organization; some structural issues |
| **0-3** (Needs Improvement) | Poor organization; confusing structure |

#### Visual Design and Formatting (5 points)

| Score | Criteria |
|-------|----------|
| **5** (Excellent) | Professional, polished design; effective use of graphics/diagrams; consistent formatting; visually appealing |
| **4** (Proficient) | Good design; adequate graphics; mostly consistent formatting |
| **3** (Developing) | Basic design; few graphics; inconsistent formatting |
| **0-2** (Needs Improvement) | Poor design; no graphics; unprofessional appearance |

#### Writing Quality (5 points)

| Score | Criteria |
|-------|----------|
| **5** (Excellent) | Clear, concise, professional writing; no grammatical errors; appropriate technical terminology; excellent readability |
| **4** (Proficient) | Clear writing; minor errors; good terminology; good readability |
| **3** (Developing) | Adequate writing; some errors; inconsistent terminology |
| **0-2** (Needs Improvement) | Poor writing; many errors; unclear communication |

#### Citations and References (4 points)

| Score | Criteria |
|-------|----------|
| **4** (Excellent) | Comprehensive citations in consistent format; all sources properly attributed; includes authoritative references |
| **3** (Proficient) | Good citations; mostly consistent; adequate sources |
| **2** (Developing) | Some citations; inconsistent format; limited sources |
| **0-1** (Needs Improvement) | Few or no citations; improper attribution |

**Presentation Subtotal**: \_\_\_\_\_ / 20 points
